ЧТО ЭТО
───────
Программа с красивым интерфейсом (PyQt6). Вы добавляете до 10 аккаунтов
Telegram и выбираете каналы/чаты. Все аккаунты работают ОДНОВРЕМЕННО и
следят за выбранными чатами. Как только в чате появляется чек
(@xrocket, @send / CryptoBot, @wallet) — программа мгновенно
активирует его («нажимает» «Получить») на всех аккаунтах.


1. УСТАНОВКА
────────────
1) Установите Python 3.10 или новее: https://www.python.org/downloads/
   (при установке поставьте галочку "Add Python to PATH").
2) Windows: просто дважды кликните по файлу  start.bat
   (он сам установит зависимости и запустит программу).
   Linux / macOS:  ./start.sh
   Или вручную:
        pip install -r requirements.txt
        python main.py


2. КАК ПОЛУЧИТЬ api_id И api_hash (один раз)
────────────────────────────────────────────
1) Откройте https://my.telegram.org и войдите по номеру телефона.
2) Выберите "API development tools".
3) Создайте приложение (название и короткое имя — любые).
4) Скопируйте  api_id (число)  и  api_hash (длинная строка).
Одни и те же api_id/api_hash можно использовать для ВСЕХ аккаунтов.
Программа запоминает их после первого ввода.


3. ДОБАВЛЕНИЕ АККАУНТОВ
───────────────────────
1) Вкладка «Аккаунты» → «＋ Добавить аккаунт».
2) Введите api_id, api_hash и номер телефона (+79991234567).
3) Нажмите «Получить код» — код придёт в Telegram (или по SMS).
4) Введите код. Если включён облачный пароль (2FA) — введите и его.
5) Аккаунт добавлен. Повторите для остальных (максимум 10).

Галочка «Активен» — включает/выключает аккаунт, не удаляя его.
Сессии хранятся в папке  sessions/  — повторно вводить код не нужно.


4. ВЫБОР ЧАТОВ И КАНАЛОВ
────────────────────────
1) Вкладка «Чаты» → выберите аккаунт → «⟳ Загрузить чаты».
2) Отметьте галочками каналы и чаты, которые нужно мониторить.
   Есть поиск и фильтр по типу (каналы / группы / личные / боты).
3) Выбор сохраняется автоматически, для каждого аккаунта отдельно.

Быстрые варианты:
 • «Мониторить ВСЕ чаты этого аккаунта» — слушать все диалоги аккаунта.
 • «Мониторить ВСЕ чаты на ВСЕХ аккаунтах» — вообще без выбора.

Важно: аккаунт должен быть участником канала/чата, чтобы его видеть.
Если нужно ловить чеки из одного канала всеми аккаунтами — вступите в
него со всех аккаунтов и отметьте его у каждого.


5. ЗАПУСК
─────────
Вкладка «Панель» → «▶ Запустить».
Все активные аккаунты подключатся (статус «● Онлайн») и начнут слушать.
В «Журнале событий» видно каждое действие:
   🎯 Чек найден → ✅ Чек активирован! 832 USDT за 340 мс
Статистика (найдено / активировано / сумма / скорость) — сверху.
Все активации сохраняются во вкладке «История» (есть экспорт в CSV).


6. КАК ЭТО РАБОТАЕТ
───────────────────
Кнопка «Получить 832 USDT» в сообщении «через @xrocket» — это ссылка
вида  t.me/xrocket?start=КОД. Нажатие на неё = отправка боту команды
/start КОД. Программа делает то же самое от имени вашего аккаунта,
но мгновенно, затем читает ответ бота и проверяет результат.
Дополнительно она:
 • находит ссылки на чеки в кнопках, тексте и скрытых ссылках;
 • понимает чеки CryptoBot (@send / @CryptoBot), xRocket, @wallet;
 • игнорирует счета на оплату (invoice) — деньги НЕ списываются;
 • если бот просит подписаться на каналы — подписывается и жмёт
   «Проверить» (можно отключить в настройках);
 • если у бота есть кнопка «Получить/Активировать» — нажимает её;
 • повторяет попытку при сбое (по умолчанию 3 раза);
 • следит за соединением и переподключается сама.


7. НАСТРОЙКИ
────────────
Внешний вид (применяется мгновенно):
 • 6 тем: Тёмная, Полночь, AMOLED, Кибер, Лес, Светлая;
 • акцентный цвет (8 пресетов или любой свой);
 • скругление углов, размер шрифта, прозрачность окна.

Поведение:
 • какие сервисы ловить (CryptoBot / xRocket / Wallet);
 • «Каждый аккаунт активирует чек сам» — для мульти-чеков, когда один
   чек могут забрать много людей. Если выключить, один чек берёт только
   первый аккаунт;
 • автоподписка на каналы;
 • минимальная сумма чека (0 = брать все);
 • задержка перед активацией (мс), число попыток, ожидание ответа бота;
 • звук при успехе, автозапуск мониторинга при старте программы;
 • прокси (socks5://user:pass@host:port или http://host:port).


8. СОВЕТЫ ДЛЯ МАКСИМАЛЬНОЙ СКОРОСТИ
───────────────────────────────────
 • Держите программу запущенной постоянно (лучше на VPS/ПК с хорошим
   интернетом).
 • Чем больше аккаунтов в нужном канале — тем выше шанс успеть.
 • Выбирайте только нужные каналы, а не «все чаты» — меньше нагрузки.
 • Оставьте задержку 0 мс.
 • Прокси общий для всех аккаунтов — если используете его, берите быстрый.


9. ЧАСТЫЕ ВОПРОСЫ / РЕШЕНИЕ ПРОБЛЕМ
───────────────────────────────────
В: Нужно ли «Получить» нажимать вручную?
О: Нет. Всё делается автоматически.

В: Статус «Нужен вход».
О: Сессия слетела (например, вы завершили её в настройках Telegram).
   Удалите аккаунт и добавьте заново.

В: Чек не активировался, в журнале «⚠ Не удалось: ...».
О: Это ответ самого бота. Частые причины: чек уже забрали (самые
   быстрые успевают первыми), чек истёк, чек предназначен для другого
   пользователя, нужно пройти проверку/капчу, на аккаунте не пройдена
   верификация в @CryptoBot / @xrocket. Для xRocket и CryptoBot аккаунт
   должен хотя бы один раз запустить бота (/start) и принять правила.
   Откройте обоих ботов вручную с каждого аккаунта и нажмите /start.

В: Ошибка FloodWait.
О: Telegram временно ограничил частые запросы. Программа сама подождёт.

В: Не приходит код.
О: Проверьте номер (с +), посмотрите код в приложении Telegram на другом
   устройстве (раздел «Telegram» в чатах), подождите пару минут.

В: Программа не видит чеки в канале.
О: Проверьте, что: 1) мониторинг запущен; 2) нужный канал отмечен
   галочкой у этого аккаунта (или включён режим «все чаты»); 3) нужный
   сервис включён в настройках; 4) в журнале аккаунт «Онлайн».

В: Где хранятся данные?
О: Папка  data/  — настройки, список аккаунтов, история.
   Папка  sessions/  — сессии Telegram (НИКОМУ не передавайте — это
   доступ к вашим аккаунтам!).


9a. УВЕДОМЛЕНИЯ В TELEGRAM
───────────────────────────
Бот присылает вам сообщение ТОЛЬКО при успешной активации чека (сумма, сервис,
аккаунт, источник, скорость). О неудачах и пропусках не пишет.
При первом запуске мониторинга (один раз за запуск программы) приходит список
всех активных аккаунтов.

Токен бота и ваш ID вписаны прямо в код — вверху файла  core/notifier.py
(BOT_TOKEN и OWNER_ID). Больше ничего настраивать не нужно.
Включать/выключать уведомления можно в «Настройки → Поведение бота».
ВАЖНО: один раз откройте своего бота-уведомителя в Telegram и нажмите /start —
иначе Telegram не даст ему написать вам.


10. ВАЖНО
─────────
 • Честно: гарантировать «100%» активацию невозможно — это зависит от
   условий самого чека (его могут забрать раньше, он может требовать
   подписки/капчи/верификации). Программа делает максимум: срабатывает
   за доли секунды, пробует несколько раз, нажимает кнопки, подписывается.
 • Используйте только свои аккаунты и на свой риск. Массовая автоматизация
   может нарушать правила Telegram и сервисов-кошельков — аккаунты могут
   быть ограничены. Не злоупотребляйте количеством подписок/вступлений.
 • Никогда не публикуйте файлы из папки sessions/ и api_hash.

Приятного использования! 🚀
