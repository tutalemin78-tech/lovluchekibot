ЗАПУСК НА RENDER (без окна, без нажатия кнопок)
════════════════════════════════════════════════
Бот запускается файлом  headless.py  — сам подключает все аккаунты и ловит чеки.
Токен уведомлений и ваш ID уже вписаны в core/notifier.py.

ШАГ 1. Сессии аккаунтов (делается ОДИН раз на вашем компьютере)
   pip install telethon
   python make_session.py
   Введите api_id / api_hash (my.telegram.org), номер, код из Telegram (и облачный пароль, если есть).
   Для нескольких аккаунтов отвечайте "y" на "Добавить ещё аккаунт".
   В конце скрипт выведет блок  API_ID=…  API_HASH=…  SESSION_1=…  (и сохранит в render_env.txt).
   ⚠ Это ЕЩЁ ОДНА отдельная сессия аккаунта. Не запускайте одновременно на ПК и на Render
     программу с ТЕМИ ЖЕ сессиями — но новые сессии из make_session.py с ПК-версией не конфликтуют.

ШАГ 2. Код на GitHub
   Загрузите папку проекта в ПРИВАТНЫЙ репозиторий (в коде лежит токен бота!).
   .gitignore уже исключает sessions/, data/, render_env.txt.

ШАГ 3. Render → New → Web Service → ваш репозиторий
   Runtime:        Python 3
   Build Command:  pip install -r requirements-headless.txt
   Start Command:  python headless.py
   Environment (вкладка Environment) — вставьте строки из шага 1:
       API_ID, API_HASH, SESSION_1, SESSION_2 …
   Необязательно:  CHATS=-1001234567890,-1009876543210  (слушать только эти чаты;
                   если не задано — слушаются ВСЕ чаты каждого аккаунта)
                   PROXY=socks5://user:pass@host:port
   Нажмите Deploy. В логах появится "Активные аккаунты (N)", а вам в Telegram придёт
   сообщение со списком аккаунтов.

ШАГ 4. Чтобы бот НЕ засыпал (важно для бесплатного плана)
   Бесплатный Web Service Render засыпает через 15 минут без входящих запросов.
   Варианты:
     а) Платный тариф Starter (≈ $7/мес) — работает без сна.
     б) Бесплатно: сервис cron-job.org или UptimeRobot — создайте задачу, которая каждые
        5 минут открывает адрес вашего сервиса (https://имя.onrender.com).
        Бот отвечает "Check Hunter OK. online=N/N" — это и проверка состояния.

ПОЛЕЗНО
   • Файлы на Render не сохраняются между перезапусками — поэтому сессии хранятся в переменных
     окружения, а не в папке sessions/. История активаций ведётся только в логах Render.
   • Каждый перезапуск сервиса = новое сообщение со списком аккаунтов в Telegram.
   • Если аккаунт пишет "не авторизован" — сессию завершили в настройках Telegram:
     создайте новую через make_session.py и обновите SESSION_n.
   • Узнать ID чата для CHATS: перешлите пост из канала боту @getidsbot.
